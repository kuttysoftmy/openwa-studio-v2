# OpenWA Studio v2 - Visual Workflow Designer

An interactive single-page application and workflow design studio specifically engineered for the self-hosted **OpenWA gateway server** integration framework. It serves as an intuitive system allowing you to draft, drag-and-drop, configure, mock, and test inbound & outbound WhatsApp message automations before launching nodes into production runtime code.

## ✨ Core Features Built-in

- **Drag-and-Drop Node Architecture**: Map out complex WhatsApp message pathways, multi-step keyword actions, external endpoints, automated replies, and custom webhooks interactively.
- **Built-in Flow Simulator**: Test your live workflow by triggering simulated messages from a target customer mock mobile number to watch the execution paths highlight dynamically in real-time.
- **Export / Import JSON Schema Configuration**: Export ready-to-run JSON layouts compatible with OpenWA configuration daemons.
- **Out-of-the-Box Ready Templates**:
  1. FAQ Keyword Responder
  2. Interactive Lead Capture
  3. After-Hours Router

## 🛠️ Tech Specs

- Powered by **Tailwind CSS (v3)**
- Pure CSS interactive node connections with automated vector mathematical curves.
- Modern dark design system styled for optimal terminal readability and productivity operations.
